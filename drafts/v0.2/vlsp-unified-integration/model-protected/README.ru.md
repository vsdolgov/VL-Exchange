# VLSP с защищёнными пакетами VLMP

[English](README.md) | Русский

Эта проверка дополняет [предыдущий эксперимент](../README.ru.md): защищёнными поставляются и сценарий, и каждый из трёх неизменённых ZIP моделей VLMP 0.2.0. Для детектора и двух разных классификаторов создаются отдельные зашифрованные оболочки с подписанными лицензиями. Каждый исполнитель вызывает собственную реализацию `load_protected`; в online-режиме он обращается к временному локальному issuer. Сценарий и модели выполняются с отдельно проверяемыми правами.

[Отчёт](reports/comparison.json) фиксирует 18 команд: оба режима проверены в эталонном исполнителе и через нативный граф VideoPipe с независимым исполнителем. В каждом режиме два golden-кадра дали ожидаемое событие; в повторно открытом сценарии искусственное истечение прав моделей после последнего вызова классификатора и до фиксации результата привело к `authorization_failed`, не изменив состояние или опубликованные события. При этом часы лицензии сценария оставались действующими. Сравниваются входы и выходы ONNX, трассы трекера, состояние, события и поля ошибок. ZIP сценария и моделей, используемые исходники и нативная программа проверяются по хешам до и после прогона.

Интеграционный адаптер сохраняет исходные разрешения отдельных вызовов моделей и проверяет их вместе с разрешением сценария перед фиксацией. Это демонстрационная интеграция для последовательной синхронной обработки: параллельные вызовы `process` не поддерживаются и не проверялись. Она не является новой стандартной реализацией API VLSP. Локальный online issuer и тестовые ключи создаются временно; промышленное развёртывание, устойчивость сети, GPU, RTSP и качество синтетических моделей этим прогоном не проверялись.

## Повторить

Из корня репозитория сначала соберите нативный адаптер и Python-окружение по [инструкции VideoPipe](../../videopipe-pilot/README.md#build-on-macos-arm64), затем выполните:

```sh
pilot=drafts/v0.2/videopipe-pilot
experiment=drafts/v0.2/vlsp-unified-integration/model-protected
PYTHONDONTWRITEBYTECODE=1 "$pilot/.venv/bin/python" "$experiment/compare.py"
```

Требуется разрешение на открытие локального порта `127.0.0.1`; `--binary` задаёт путь к ранее собранному бинарнику, `--output` — путь к отчёту. При ошибке старый отчёт PASS удаляется. Отдельные регрессионные тесты жизненного цикла и сохранения предыдущего разрешения не запускают VideoPipe и выполняются командой:

```sh
python -m pytest -q -p no:cacheprovider --import-mode=importlib \
  drafts/v0.2/vlsp-unified-integration/model-protected/tests
```
