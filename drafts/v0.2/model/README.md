# VL Model Package 0.2 — проект профиля детекции

[Спецификация](spec/SPECIFICATION.md), [схема манифеста](spec/model-package.schema.json), [схема детекций](spec/schemas/detections.schema.json), [пример модели](examples/vl-color-detector/) и [его ZIP](examples/vl-color-detector.zip).

Идентификатор проекта — `0.2.0-detection-draft.1`. Он отличается от публичного проекта профиля классификации `0.2.0-draft.1`; единой схемы для них пока нет. Пример использует синтетическую необученную модель ONNX и CPU, поэтому не служит оценкой качества реальной детекции. Совместимость с Box 5 отдельно не подтверждена.

Экспериментальный загрузчик и тесты находятся в `src/` и `tests/`; инструкция по запуску приведена в [обзоре черновика](../README.md).
