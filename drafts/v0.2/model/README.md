# VL Model Package 0.2 — профиль детекции

[Спецификация](spec/SPECIFICATION.md), [схема манифеста](spec/model-package.schema.json), [схема детекций](spec/schemas/detections.schema.json), [пример модели](examples/vl-color-detector/) и [его ZIP](examples/vl-color-detector.zip).

Спецификация прежнего профиля детекции сохраняет исторический идентификатор пакета `0.2.0-detection-draft.1`; исходная схема отличается от классификации `0.2.0-draft.1`. Новый [объединённый VLMP 0.2.0](../vlmp-unified/README.ru.md) имеет отдельную общую схему, а эти прежние пакеты не меняются автоматически. Пример использует синтетическую необученную модель ONNX и CPU, поэтому не служит оценкой качества реальной детекции. Совместимость с Box 5 отдельно не подтверждена; финализация не является отраслевым признанием или заявлением промышленной готовности.

Экспериментальный загрузчик и тесты находятся в `src/` и `tests/`; инструкция по запуску приведена в [обзоре выпуска](../README.md).
