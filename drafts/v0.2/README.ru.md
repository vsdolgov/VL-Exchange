# Спецификации VL Exchange 0.2

**Русский | [English](README.md)**

Здесь опубликованы спецификации проекта VL Exchange: VLSP 0.2, объединённый VLMP 0.2.0 и прежний отдельный профиль детекции VLMP. Их выпуск не означает утверждения отраслевого стандарта или готовности реализаций к промышленной эксплуатации. Справочные реализации и пилот остаются экспериментальными. Исторический путь `drafts/v0.2` сохранён для совместимости ссылок и не обозначает текущий статус документов. Прежние публичные примеры и контракты доступны с [главной страницы репозитория](../../README.ru.md).

## Что проверено локально

VideoPipe использован как пример другой среды исполнения, чтобы продемонстрировать универсальность подхода и переносимость одного пакета VLSP. Это не обязательная зависимость стандарта; один пилот не доказывает совместимость со всеми платформами.

Один неизменённый ZIP сценария с SHA-256 `1461028eb6176c72bb0229eb8b28b7e697b6a4fcc1f7d420e095631bf4e0f332` запускался в эталонном host и отдельно реализованном host через граф C++ VideoPipe. Синхронный сценарий использует детектор, IoU-трекер и два разных классификатора. Исполнители используют общие загрузчики моделей, ONNX Runtime и компоненты защиты, поэтому независимость относится не ко всем компонентам. Платформа стороннего производителя в испытании не участвовала.

После согласования ошибок и жизненного цикла прошли **115 из 115 сравнений команд**, в том числе совпали поля ошибок для 28 ожидаемых отказов. В отдельной проверке входной очереди совпали **12 из 12 сценариев** на обоих host: переполнение, остановка, повторный запуск, ошибка и неизвестная фиксация после потери ответа. При непрерывной подаче с `block` каждый host обработал **120 из 120 кадров** без потерь; отдельный залп из 300 кадров проверил явный учёт пропусков. Регрессионный набор завершился с результатом **142 теста пройдены**.

[Отчёт об очереди](reports/STREAM-VERIFICATION.md), [машинные результаты очереди](reports/stream-load.json), [сравнение исполнителей](reports/comparison.json) и [результат тестов](reports/stream-pytest.txt) — архив локального эксперимента. Для повторного запуска доступны [исходники пилота VideoPipe и инструкция](videopipe-pilot/README.md); сборка требует внешних зависимостей, а численные результаты зависят от окружения.

Это локальный синтетический эксперимент на CPU с кадрами 4×2 пикселя и необученными ONNX-моделями. Он не подтверждает качество аналитики или производительность в промышленной эксплуатации. Ограниченная очередь находилась в Python worker перед сценарием, после передачи кадра через нативные компоненты VideoPipe: она не ограничивала upstream-очереди VideoPipe и память заблокированных отправителей. RTSP, кодеки, GPU, надёжная доставка, восстановление после аварии и принятие внешней платформой этим тестом не подтверждены. Через VideoPipe проверен синхронный сценарий; **асинхронная МЛЛМ через VideoPipe не проверена**.

## Async-прототип и соответствие

Профиль async описывает последующую доставку коррелированного результата МЛЛМ. Локальные эксперименты с прототипом и отдельный тест с МЛЛМ не подтверждают полного соответствия профилю. В частности, профиль требует идемпотентной повторной подачи, а текущий прототип `AsyncScenarioExecutor` отклоняет повтор одного задания внутри одного вызова `process`. Таймаут также не гарантирует прерывания уже отправленного внешнего запроса; восстановление, хранение media и внешняя доставка требуют отдельных гарантий и проверок.

Необязательные профили — самостоятельные возможности, а не автоматические свойства любого host. Host следует заявлять поддержку только реализованных семантики и проверок. В профиле потока вместимость очереди считает ожидающие кадры; обрабатываемый кадр идёт дополнительно. Необработанная ошибка callback или потерянный ответ могут произойти после фиксации, поэтому её результат может быть неизвестен и не доказывает откат либо обработку ровно один раз.

## Проверка включённых тестов

Установите зависимости из корневого `requirements.txt` в Python 3.12 и выполните из корня репозитория:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH='drafts/v0.2/scenario/src:drafts/v0.2/model/src:drafts/v0.2/security-runtime/src' python -m pytest -q -p no:cacheprovider --import-mode=importlib drafts/v0.2/scenario/tests drafts/v0.2/model/tests
```

Эти тесты проверяют включённые reference-компоненты и имитаторы провайдеров. Для повторного сравнения с VideoPipe нужна отдельная [сборка нативного пилота](videopipe-pilot/README.md). Эксперимент с внешней МЛЛМ в эти тесты не входит.
