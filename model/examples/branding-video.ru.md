# Атрибуция и брендинг: демонстрационное видео

[English](branding-video.en.md)

Синтетический 16-секундный ролик показывает, как принимающая платформа могла бы указывать авторов видеоаналитики рядом с её результатами. В первой половине показан один вымышленный разработчик, Example Lab; во второй — два: Example Lab и Vision Workshop. Имена взяты из [публичного примера VLMP](attribution-channel-classifier/model-package.json).

- [Исходное видео без наложений](branding-video-original.mp4)
- [Демонстрация с брендингом](branding-video-overlay.mp4)
- [Скрипт формирования роликов](branding-video-render.py)

Сцена, люди, движения и рамки детекций нарисованы программно. Ролик не показывает работу реального детектора, интеграцию с чужой платформой или готовый продукт для видеоэкспорта. Подписи «LIVE VIEW» и «EXPORT COPY» иллюстрируют возможные режимы. Для их работы принимающая платформа должна реализовать эти режимы и поддержать экспериментальный [профиль Attribution & Branding](../../docs/ru/ATTRIBUTION.md). Пожелание автора или условие лицензии не могут технически помешать платформе убрать подпись. Исходный и размеченный ролики — отдельные файлы.

Оба опубликованных файла: H.264/MP4, 1280 × 720, 20 кадров/с, без звука. Скрипт создаёт новый исходный ролик, отдельную копию с наложениями и два кадра для предварительного просмотра. Он читает локальные фиктивные метаданные пакета и не обращается к сети.

## Повторное создание

Нужны Python 3, Pillow, FFmpeg с `libx264` и системные шрифты (Arial на macOS либо DejaVu Sans / Liberation Sans на Linux). Установите Pillow в виртуальное окружение и запустите из корня репозитория:

```sh
python -m pip install 'Pillow>=10,<13'
python model/examples/branding-video-render.py --output-dir /tmp/vl-branding-demo
```

Выходная папка должна быть новой или пустой: скрипт откажется перезаписывать существующие файлы. Если системных шрифтов нет, укажите `--font /путь/к/обычному.ttf --bold-font /путь/к/полужирному.ttf`; права на их использование нужно проверить самостоятельно. Вид и байты результата могут отличаться в зависимости от шрифтов и версий Pillow и FFmpeg. Побайтовая воспроизводимость не заявляется. Пример иллюстративный и не является проверкой производительности или межвендорной совместимости.
